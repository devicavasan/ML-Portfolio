#  Machine Learning Portfolio

A collection of end-to-end ML projects covering regression, classification,
and clustering — built using Python, Scikit-learn, TensorFlow, and Keras.

---

##  Projects

###  Regression
| Project | Description | Libraries |
|--------|-------------|-----------|
| [Housing Price Predictor](./regression/housing-price-predictor) | Predicts house prices based on location, size & amenities | sklearn, pandas |
| [Stock Price Forecasting](./regression/stock-price-forecasting) | Time series model to forecast stock prices | pandas, statsmodels |

###  Classification
| Project | Description | Libraries |
|--------|-------------|-----------|
| [MNIST Digit Recognition](./classification/mnist-digit-recognition) | Neural network trained on MNIST dataset | TensorFlow, Keras |
| [Iris Species Classifier](./classification/iris-species-classifier) | Classifies iris flower species | sklearn |
| [Spam Email Detector](./classification/spam-email-detector) | Text classification to filter spam emails | sklearn, NLTK |
| [Credit Risk Assessment](./classification/credit-risk-assessment) | Scores creditworthiness from financial data | sklearn, pandas |
| [Anomaly Detection](./classification/anomaly-detection) | Detects outliers for fraud detection use cases | sklearn |
| [Signal Classification](./classification/signal-classification) | Distinguishes normal vs abnormal physiological signals | sklearn, numpy |
| [Breast Cancer Diagnosis](./classification/breast-cancer-diagnosis) | Classifies malignant vs benign tumors from imaging data | sklearn, Keras |

###  Clustering
| Project | Description | Libraries |
|--------|-------------|-----------|
| [Medical Image Diagnosis](./clustering/medical-image-diagnosis) | Diagnoses diseases from X-ray images using clustering | Keras, OpenCV |
| [Crop Disease Detection](./clustering/crop-disease-detection) | Identifies crop diseases from plant leaf images | TensorFlow, OpenCV |

**Open in Colab** badge inside each notebook.
